# Plataforma de Profissionais Autônomos (Projeto Integrador)

Bem-vindo ao repositório do meu Projeto Integrador! Esta é um site focado em conectar clientes e profissionais autônomos de forma rápida, segura e interativa. (Inspirado no Getninjas)

## 🚀 O Projeto

O objetivo é criar um sistema completo onde:
- **Profissionais** podem anunciar seus serviços (com foto, descrição, preço médio e contato telefônico obrigatório).
- **Clientes** podem buscar serviços por palavras-chave, além de navegar por categorias e subcategorias.
- Conta com um **Mural de Perguntas e Respostas** estilo rede social dentro de cada anúncio, ideal para tirar dúvidas rápidas antes de fechar negócio.
- Possui um sistema de avaliação e notas para ranquear os melhores profissionais.

## 🛠️ Tecnologias Utilizadas (Stack)

*   **Front-end:** HTML5, CSS3, JavaScript
*   **Back-end:** PHP
*   **Banco de Dados:** MySQL
*   **Segurança:** Criptografia de senhas nativa (`password_hash` do PHP), prevenção de ataques comuns.

## 📋 Funcionalidades Principais (Fase 1)

1.  **Sistema de Login Seguro:** Autenticação protegida no banco de dados.
2.  **Gestão de Anúncios:** CRUD (Criar, Ler, Atualizar, Deletar) de anúncios de serviços.
3.  **Organização Refinada:** Categorias e Subcategorias (ex: Reformas -> Eletricista).
4.  **Mural Social (Q&A):** Interação direta no perfil do anúncio.
5.  **Busca Inteligente:** Motor de busca integrado na página inicial.

## 🗄️ Estrutura do Banco de Dados (Entidades)

*   `usuarios`: Dados de acesso, perfil e contato.
*   `categorias` & `subcategorias`: Organização do catálogo de serviços.
*   `anuncios`: Detalhes do serviço prestado.
*   `avaliacoes`: Notas e feedbacks dos clientes.
*   `perguntas_respostas`: Mural de interação (Perguntas/Respostas).
